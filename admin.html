⚙️ Verwaltung

Deine eigentliche Veröffentlichung läuft weiterhin über dein GitHub-Repository und die automatische TweakOS-Release-Action.

🛠️ Repository 📦 Releases

🚀 Neue TweakOS-Version veröffentlichen

  1. Ändere deinen TweakOS-Code im Repository.
  2. Öffne src/TweakOS/Services/ReleaseService.cs.
  3. Erhöhe dort CurrentVersion, z. B. von 5.0.0 auf 5.0.1.
  4. Committe die Änderung auf main.
  5. GitHub Actions baut automatisch TweakOS.
  6. GitHub erstellt automatisch das neue Release.
  7. Die Website erkennt automatisch die neue Version.
