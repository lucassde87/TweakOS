# TweakOS v5.0.0

## Neu
- Neue Tweaking-Oberfläche mit Suche.
- BAT- und PowerShell-Tweaks werden passend gestartet.
- Online-Katalog bleibt zentral.
- App prüft GitHub Releases auf neue Versionen.
- Öffentliche Download- und Changelog-Website.
- GitHub Actions baut automatisch einen Windows-x64 Release-ZIP.
- Nur Repository-Schreibberechtigte können neue Releases veröffentlichen.

## Sicherheit
- Kein Admin-Passwort im Frontend.
- Kein GitHub-Token im Browser.
- Kritische/ungeprüfte Tweaks bleiben gekennzeichnet und benötigen Bestätigung.
